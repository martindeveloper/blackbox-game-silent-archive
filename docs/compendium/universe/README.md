# Universe / World

Reusable canon for future games in the Silent Archive universe.

These docs define the shared world: synthetic labor, unresolved personhood, corporate research, legal procedure, and the moral rules that make this universe feel like itself.

They should be used before creating a new city, company, facility, protagonist, or legal case in this universe.
